# 📊 E-Commerce Sales Analysis Dashboard Using Tableau

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data using Tableau Public. The dashboard provides visual insights into sales trends, product performance, regional sales, and category-wise performance to support better business decision-making.

## 🎯 Project Objectives

* Analyze sales trends over time.
* Compare sales performance across regions.
* Identify products contributing to sales.
* Explore category-wise sales distribution.
* Discover business patterns through data visualization.
* Support data-driven decision-making.

## 🛠️ Tools and Technologies

* Tableau Public
* Microsoft Excel
* Data Visualization
* Exploratory Data Analysis (EDA)

## 📈 Dashboard Features

* Monthly sales trend analysis
* Top products by sales
* Regional sales analysis
* Category-wise sales distribution
* Category and region performance analysis
* Product sales contribution using a Packed Bubble Chart
* Interactive dashboard filters
