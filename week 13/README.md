# 📊 E-Commerce Sales Analysis Dashboard Using Tableau

## 📌 Project Overview

This project analyzes e-commerce sales data using Tableau Public. It explores sales trends, product performance, regional sales, and category-wise performance through interactive visualizations.

## 🎯 Objectives

* Analyze sales trends over time.
* Compare sales performance across regions.
* Explore product-wise sales performance.
* Understand category-wise sales distribution.
* Identify meaningful business insights.
* Support data-driven decision-making.

## 🛠️ Tools and Technologies

* Tableau Public
* Microsoft Excel
* Data Visualization
* Exploratory Data Analysis (EDA)

## 📈 Dashboard Features

* Monthly sales trend analysis
* Product sales comparison
* Regional sales analysis
* Category-wise sales distribution
* Category and region performance analysis
* Product sales contribution using a Packed Bubble Chart
* Interactive dashboard filters
